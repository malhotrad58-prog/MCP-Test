## Title
Login to SauceDemo with Config Credentials

## Requirement Reference

## Preconditions
- The URL is configured in `src/test/resources/config.properties`.
- The valid login credentials are available in `src/test/resources/login_credentials.xlsx`.
- The browser is available and can run in headless mode.

## Test Steps
1. Launch the SauceDemo application using the configured base URL.
2. Read the valid username and password from the Excel file.
3. Enter the username in the Username field.
4. Enter the password in the Password field.
5. Click the Login button.
6. Wait for the dashboard or inventory page to load.

## Expected Result
- The user is successfully logged in.
- The inventory page is displayed.
- The page title is `Products`.
- No login error message is shown.
